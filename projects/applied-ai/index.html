SELECTED AI INTERNSHIP WORK · 2026

Applied AI: From Detection to Structured Reasoning

I am Julia Zhu, a Computer Science and Statistics undergraduate at UW–Madison. During my May–September 2026 AI algorithm internship at Zhejiang Supcon Information (中控信息), I worked across three connected areas: vehicle detection, vision-language model evaluation, and language-model attribute extraction.

The common thread was building workflows that connect model inputs, evaluation, error diagnosis, and deployment. My work combined data preparation and model training with structured checks that make model behavior easier to inspect.

1. Vehicle Detection & Assisted Labeling

YOLO11 · YOLO-World · ONNX · Data quality

Problem. A detection workflow needs consistent labels and class definitions as the range of target vehicles expands. Training, evaluation, and exported inference also need to use the same class mapping.

Implementation. I built a YOLO11 pipeline covering dataset preparation, training, evaluation, and ONNX export, and expanded the label taxonomy from three to eight classes. To support annotation, I developed YOLO-World-assisted pre-labeling using class-specific text prompts and confidence controls.

The labeling workflow included two-stage non-maximum suppression and visual quality checks. I also worked on class remapping for continued training, connecting changes in the dataset to the model configuration rather than treating annotation and training as separate tasks.

Evaluation approach. I used model evaluation alongside visual inspection of predictions and labels. This helped distinguish class-definition and annotation problems from model errors before carrying changes into the next training run.

2. Multimodal Scenario Evaluation

Vision-language models · Prompt engineering · Error analysis

Problem. Traffic and municipal images can contain ambiguous evidence. A plausible model explanation is not enough to establish that a specific event has actually occurred.

Implementation. I developed prompts and an automated evaluation framework for 15 traffic and municipal scenarios. The workflow combined initial routing with more detailed verification, using structured outputs and programmatic consistency checks to make decisions inspectable.

I iterated on staged evidence checks and reverse-review prompts, then examined false-positive cases to understand where the model had inferred more than the image supported. Routing and targeted verification also provided a way to avoid redundant calls to the model.

Evaluation approach. I organized error analysis by scenario and decision stage, so prompt revisions could be tied to identifiable failure cases rather than judged only from a few convincing examples.

3. Language-Model Attribute Extraction

CCKS2026 · LoRA/QLoRA · vLLM · Structured extraction

Problem. Attribute extraction requires a model to convert text into a consistent output schema. Errors may arise from the extraction instruction, the model configuration, or disagreements in how a rule is interpreted.

Implementation. For CCKS2026 extraction workflows, I iterated on prompt engineering, LoRA/QLoRA fine-tuning, and vLLM inference. I compared model configurations and kept error analyses to guide subsequent revisions.

Evaluation approach. I examined incorrect and inconsistent outputs across configurations, using those cases to separate prompt-related issues from behavior that required a different training or inference setup.
